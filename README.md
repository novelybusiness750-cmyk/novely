# NOVÉLY

Assistant commercial intelligent pour entrepreneurs francophones.

## Objectif
Aider les petites entreprises à trouver des clients et à mieux présenter leurs offres.

## Fonctionnalités prévues
- Définir son client idéal
- Rédiger des offres commerciales
- Créer des messages de prospection
- Préparer des publications pour les réseaux sociaux

## Projet
NOVÉLY est en cours de création. Les fonctionnalités seront développées progressivement.
